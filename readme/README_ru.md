## Почему Fluxora

Большинство прокси-клиентов считают «подключилось» финишем, а правила, журналы и состояние соединений прячут во вложенных подменю. Fluxora делает наоборот: **сначала состояние должно быть видно, потом действие должно быть достижимо.**

Он построен на ядре Mihomo (Clash Meta) с Flutter и даёт одинаковую информационную архитектуру на десктопе и мобильных — дашборд, прокси, профили, инструменты, журналы, запросы, ресурсы, скрипты и соединения: девять страниц, у каждой своя роль, ничего не навалено и ничего не спрятано.

Три принципа дизайна: **сдержанность** (без декоративных анимаций и неонового свечения), **понятность** (состояние всегда заметнее действия), **проверяемость** (открытый код, без встроенной системы аккаунтов, без необъявленных закрытых зависимостей).

## Ключевые преимущества

- **Современный интерфейс** — Material 3 и единый набор дизайн-токенов (цвет, типографика, отступы, радиусы, анимация), а не простая переделка вышестоящего интерфейса.
- **Единообразие платформ** — Windows, macOS, Linux и Android используют одну кодовую базу Flutter и одну информационную архитектуру.
- **Полный контроль над прокси** — режимы выхода rule / global / direct, выбор групп, измерение задержки, цепочки прокси и резидентный выход.
- **Перехват сети** — виртуальный адаптер TUN и системный прокси, на десктопе — постоянный трей и глобальные горячие клавиши.
- **Темы и материалы** — светлая / тёмная / как в системе, чистый чёрный, четыре материала (классика / матовое стекло / жидкое стекло / облегчённый) и тема «Обсидиан». Поддерживаются системный подбор цвета и собственный акцент.
- **Открытость и проверяемость** — GPL-3.0; ядро, скриптовый движок и зависимости доступны для проверки, облачных аккаунтов нет.

## Возможности

### Подключение

- Системный прокси (десктоп)
- Виртуальный адаптер TUN, включая тип стека и режим маршрутизации
- Режимы выхода: rule / global / direct
- Список соединений с трафиком в реальном времени и закрытие соединений
- Умная автоостановка: остановить прокси после подключения к заданной сети

### Узлы

- Группы прокси: select / url-test / fallback / load-balance
- Измерение задержки и переключение узлов
- Ручное переключение действует один раз и не сохраняется как блокировка; группы url-test возвращаются к узлу с наименьшей измеренной задержкой

### Цепочка прокси

- Двухзвенный релей через входной хоп и статический резидентный IP, передача в порядке вход → выход
- Для цепочки создаётся отдельная карточка группы (🔗 цепочка прокси), управляемая рядом с обычными группами
- Выбор узла и состояние по каждому хопу (вход / выход), задержка и диагностика по хопам
- Предпросмотр топологии маршрута: достижимость и задержка каждого хопа с первого взгляда
- Включается для каждого профиля отдельно, поддерживает явные цепочки с несколькими входами

### Cloudflare WARP

- Встроенный выход WARP с отдельной группой «🛡️ выход WARP», совместимой с любой группой прокси
- Регистрация аккаунта Cloudflare в один клик, привязка ключа WARP+
- Настройка endpoint / порта, чистых IP, MTU, переключателя UDP и удалённого разрешения DNS
- Выбор режима маршрутизации и указание вышестоящего дозвонщика (default dialer proxy)

> Возможность подключения зависит от узла, сети и состояния сервисов Cloudflare.

### Профили

- Несколько профилей (локальные файлы / ссылки подписки)
- Импорт и обновление профилей, провайдеры правил
- Объединение нескольких подписок
- JavaScript для обработки правил и конфигурации

### Инструменты

- Проверка сети, локальный IP, определение разблокировки медиа
- Переопределение DNS, Sniffer и NTP
- Переключатель IPv6, потребление памяти, статистика трафика
- Журналы, записи запросов, диагностика соединений
- Необязательная информация о рисках IP (по умолчанию выключена)

### Интерфейс и персонализация

- Компоненты главной страницы можно добавлять, сортировать и удалять; основное действие подключения остаётся всегда
- Боковая панель на десктопе переключается между 208px с подписями и 68px с иконками; на мобильных — плавающая навигация
- Светлая / тёмная / как в системе, чистый чёрный (OLED)
- Четыре материала и тема «Обсидиан»; сила линзы и прозрачность настраиваются отдельно
- Три источника цвета: фирменная палитра, системный цвет (Android Material You), свой акцент
- Анимация привязана к реальному состоянию и учитывает системную настройку «уменьшить движение»
- Трей на десктопе, глобальные горячие клавиши, автозапуск

### Фирменные иконки

Восемь стилей, у каждого отдельная тёмная и светлая версия: Official, Classic, Aqua, Premium, Speed, Sky, Sunset, Blue Night.
Открыть **Настройки → Тема → Иконка приложения**; цвет иконки и тема страницы настраиваются независимо.

Пакеты публикуются в **[GitHub Releases](https://github.com/Tiam9173/fluxora/releases)** с именем `Fluxora-<version>-<platform>`.

Текущий стабильный релиз — **[v1.1.1](https://github.com/Tiam9173/fluxora/releases/tag/v1.1.1)**. **Предпросмотр 1.1.2-rc.2 в ветке `dev` приостановлен**; строка версии в исходниках не означает, что пакет уже опубликован — актуальное состояние и загрузки смотрите в Releases.

| Платформа | Форматы | Архитектуры |
|---|---|---|
| Windows 10 / 11 | установщик `setup.exe` · `portable.zip` | amd64 · amd64-compatible · arm64 |
| macOS 12+ | `.dmg` | arm64 · amd64 · amd64-compatible |
| Linux | `.AppImage` · `.deb` · `.rpm` | amd64 · amd64-compatible (все три формата) · arm64 (deb) |

> Варианты `-compatible` предназначены для старых CPU и систем (устройств без новых наборов инструкций); на обычных устройствах выбирайте обычную сборку. Таблица показывает поддерживаемые форматы — она не означает, что каждая пробная сборка выпустила все из них.

## Установка

### Windows

Скачайте установщик `setup.exe` либо распакуйте `*-windows-amd64-portable.zip` и запустите `Fluxora.exe` напрямую.

### Android

Скачайте из Releases APK под архитектуру устройства и установите вручную (sideload).

### Linux

Выберите `.AppImage`, `.deb` или `.rpm` под свой дистрибутив.

### macOS

Скачайте DMG под свою архитектуру и откройте его.

## Использование и конфиденциальность

1. Импортируйте свою подписку или локальный профиль в разделе «Профили» и выберите нужный.
2. Выберите узел в разделе «Прокси» и подключитесь. Fluxora не предоставляет подписки или прокси-серверы.
3. TUN и системный прокси работают в зависимости от платформы и прав; системный прокси влияет только на приложения, которые его соблюдают.

Обновление подписок, измерение задержки, проверка выходного IP / разблокировки и регистрация WARP обращаются к соответствующим сервисам. Информация о рисках IP по умолчанию выключена; при включении и запросе проверяемый IP отправляется поставщику этих данных. **Не читайте «нет облачного аккаунта Fluxora» как «нет сторонних сетевых запросов».** Перед публикацией профилей, журналов или диагностики удалите адреса подписок, ключи и личные данные.

## FAQ

### Что такое Fluxora?

Открытый кроссплатформенный клиент маршрутизации на ядре Mihomo (Clash Meta), построенный на Flutter.

### Какие платформы поддерживаются?

Windows, macOS, Linux и Android. Официального клиента для iOS нет, и он не планируется.

### Проект открытый? Под какой лицензией?

Да — **GPL-3.0**. Полный текст в [LICENSE](../LICENSE).

### Как импортировать профиль?

В разделе «Профили» добавьте ссылку подписки или импортируйте локальный файл, выберите его и подключитесь. Ссылки `fluxora://install-config` импортируются напрямую.

### Чем отличается TUN от системного прокси?

Системный прокси влияет только на приложения, соблюдающие системную настройку прокси. TUN перехватывает трафик ниже, через виртуальный адаптер, поэтому охватывает больше, и обычно требует прав администратора. На десктопе оба включаются независимо.

### Почему нет сборки для iOS?

iOS требует отдельной реализации Network Extension и распространения с подписью разработчика. В текущие планы это не входит.

### Вы собираете мои данные?

Нет. У Fluxora нет облачного сервиса аккаунтов и встроенной телеметрии. Но обновление подписок, измерение задержки, проверки IP и разблокировки обращаются к сторонним сервисам согласно вашей конфигурации.

## Разработка

**Требования**: Flutter (с Dart), Android SDK/NDK и JDK, а также инструменты платформы (Visual Studio Build Tools для Windows, Xcode для macOS, библиотеки GTK для Linux). Ядро и Helper — компоненты на Go / Rust, для них нужны свои тулчейны.

```bash
git clone https://github.com/Tiam9173/fluxora.git
cd fluxora
flutter pub get
dart run build_runner build -d
flutter analyze
flutter test
flutter run            # или flutter build windows --release
```
