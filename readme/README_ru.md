## Почему Fluxora

Большинство прокси-клиентов считают «подключилось» финишем и складывают правила, журналы и состояние подключений в многоуровневые подменю. Fluxora делает наоборот: **сначала делает состояние видимым, а затем делает действия достижимыми.**

В основе — ядро Mihomo (Clash Meta), сборка на Flutter. На десктопе и мобильных устройствах используется одна и та же информационная архитектура — панель, прокси, профили, инструменты, журналы, запросы, ресурсы, скрипты и подключения: девять страниц, каждая со своей ролью, без нагромождения и без сокрытия.

В основе дизайна три принципа: **сдержанность** (никаких декоративных анимаций и неоновых эффектов), **ясность** (состояние всегда заметнее действия), **проверяемость** (открытый код, отсутствие учётных записей, никаких необъявленных закрытых зависимостей).

Fluxora — самостоятельный продукт и не имеет официальной связи ни с одним из вышестоящих проектов. Его происхождение и лицензионные обязательства полностью задокументированы в [NOTICE](../NOTICE).

## Ключевые преимущества

- **Современный интерфейс** — дизайн-система Material 3 и единые токены (цвет / кегль / отступы / радиусы / анимация). Это не косметическая переделка вышестоящего интерфейса.
- **Единообразие на всех платформах** — Windows, macOS, Linux и Android используют один и тот же код на Flutter и одну информационную архитектуру.
- **Полный контроль над прокси** — три режима выхода: правила / глобальный / напрямую; выбор групп прокси, проверка задержки, цепочка прокси с фронтальным и выходным релеем.
- **Перехват сети** — виртуальный адаптер TUN и системный прокси, постоянный трей и глобальные горячие клавиши на десктопе.
- **Система тем** — светлая / тёмная / как в системе, полностью чёрный режим, 7 фирменных наборов цветов; на Android — динамические цвета Material You.
- **Открытый и проверяемый код** — GPL-3.0. Ядро, движок скриптов и зависимости доступны для изучения; облачных учётных записей нет.

## Возможности

### Подключение
- Системный прокси (десктоп)
- Виртуальный адаптер TUN (с выбором типа стека и режима маршрутизации)
- Режимы выхода: правила / глобальный / напрямую
- Список подключений с трафиком в реальном времени, закрытие подключения
- Умный запуск и остановка: при подключении к заданной сети прокси-сервис останавливается автоматически

### Узлы
- Группы прокси: выбор / автотест скорости / отказоустойчивость / балансировка
- Проверка задержки и переключение узлов
- Цепочка прокси (фронтальный / выходной релей)

### Профили
- Управление несколькими профилями (локальные файлы / ссылки подписки)
- Импорт и обновление профилей, ресурсы правил (rule providers)

### Инструменты
- Проверка сети, внутренний IP, проверка разблокировки медиа
- Переопределение DNS, Sniffer, NTP
- Переключатель IPv6, потребление памяти, статистика трафика
- Журналы, записи запросов, диагностика подключений
- Скрипты JavaScript (обработка правил и конфигурации)

### Персонализация
- Светлая / тёмная / как в системе
- Полностью чёрный режим (OLED)
- 7 фирменных наборов цветов + свой основной цвет
- Динамические цвета Material You на Android
- Трей на десктопе, глобальные горячие клавиши, автозапуск

## Установка

### Windows
1. Скачайте портативную сборку для Windows (`*-windows-amd64-portable.zip`) со страницы Releases.
2. Распакуйте в любой каталог (установка не требуется).
3. Запустите `Fluxora.exe`.

> Установщик (мастер `.exe`) ещё готовится — пока используйте портативную сборку.

### Android
Скачайте APK для своей архитектуры со страницы Releases и установите вручную либо дождитесь версии в магазине приложений.

### Linux
Скачайте AppImage / deb / rpm со страницы Releases (в зависимости от состава релиза).

### macOS
Скачайте DMG для своей архитектуры со страницы Releases.

> Официальные установочные пакеты для Linux и macOS ещё не собраны — ориентируйтесь на фактическое содержимое страницы Releases.

## FAQ

### Что такое Fluxora?
Открытый кроссплатформенный клиент сетевой маршрутизации на ядре Mihomo (Clash Meta), собранный на Flutter.

### Какие платформы поддерживаются?
Windows, macOS, Linux и Android. Для iOS официального клиента нет, и в текущие планы он не входит.

### Как Fluxora связан с вышестоящими проектами?
Fluxora — **самостоятельный продукт**, а не официальный релиз какого-либо вышестоящего проекта. Это независимое продолжение проекта Bettbox, поверх которого самостоятельно разработаны бренд, интерфейс, дизайн-система и компоненты для Windows. Полное описание происхождения и лицензионных обязательств — в [NOTICE](../NOTICE).

### Проект открытый? Под какой лицензией?
Открытый, под **GPL-3.0**. Полный текст — в [LICENSE](../LICENSE).

### Как импортировать конфигурацию?
На странице «Профили» добавьте ссылку подписки или импортируйте локальный файл конфигурации, затем выберите его — и можно подключаться. Также поддерживается прямая установка по ссылке `fluxora://install-config`.

### Чем TUN отличается от системного прокси?
Системный прокси влияет только на приложения, которые соблюдают системные настройки прокси. TUN перехватывает трафик на более низком уровне через виртуальный адаптер, поэтому охват шире и обычно требуются права администратора. На десктопе оба режима включаются независимо.

### Почему для некоторых платформ нет установочных пакетов?
Для каждой платформы нужна своя среда сборки (для Linux — инструментарий GTK, для macOS — подпись и нотаризация через Xcode). Они будут добавлены по мере первого стабильного релиза.

### Собираются ли мои данные?
Нет. Fluxora не предоставляет облачных учётных записей и не имеет встроенной отправки статистики. Подписки, правила и сетевые запросы полностью определяются выбранной вами конфигурацией.

## Разработка

**Требования**: Flutter (вместе с Dart), Android SDK/NDK и JDK, инструменты сборки целевой платформы (Visual Studio Build Tools для Windows, Xcode для macOS, библиотеки разработки GTK для Linux). Ядро прокси и Helper — компоненты на Go / Rust, для них нужны соответствующие инструментарии.

```bash
git clone https://github.com/Tiam9173/fluxora.git
cd fluxora
flutter pub get
dart run build_runner build -d
flutter run            # или flutter build windows --release
```
