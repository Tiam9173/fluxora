# 1.1.4-rc.1 应用反馈修复

本次应用修复同步 dev 和 preview/1.1.4-rc.1。既有 Core X Go 补丁仅保留在预览分支；本轮没有新增 Go 生产补丁，没有包含热点共享代码。

## 选择器

- 链式、WARP、订阅前后置共用紧凑标题栏，定位和测速同排；48px 操作区域，窄屏、大字号及桌面布局已实际截图检查。
- GLOBAL 按代理页面的真实成员展示，包括策略组、隐藏组成员和生成的出口；调用方仍排除会形成自引用的选项。
- 长按列表节点只测试该节点，不切换节点、不关闭卡片，不自动选择最快节点；策略组行也支持长按测速。
- 中转策略组生成独立配置，保留策略类型、节点集合和已有筛选条件。用户手动切换原策略组时同步链路副本；同步失败尝试回滚，不记录假成功。
- include-all 的入口在注入出口之前固定其成员范围，避免把自己的新出口包含进去而形成循环。配置刷新时重新生成范围。
- 前置、后置分别固定提供 WARP 入口、WARP 出口，不依赖运行时 GLOBAL 是否展示 WARP；使用已有 WARP 账户参数，不更改全局 WARP 模式。
- 后置维持已有出口变体的语义：生成对应链路供代理页面选择，不擅自改变用户当前选择。

## DNS

- 覆写默认查询：`https://dns.alidns.com/dns-query` 和 `https://doh.pub/dns-query`。
- 节点域名默认使用以上两个服务的 `#DIRECT` 路径；引导解析为 `223.5.5.5`、`119.29.29.29`。
- 精确匹配旧默认值时迁移：移除示例私有域名、通配系统策略和单个固定 IP 的 DoH。保留自定义值。
- 未覆写且订阅启用 DNS 时保留订阅配置；订阅没有启用 DNS 时使用独立的 system/redir-host 配置，不再混入覆写的解析器。
- 节点专用解析器和 hosts 映射继续保留，过滤指向自身监听端口的引导解析器，避免解析回环。
- Android 获取 system DNS 时只接受底层非 VPN 网络，避免把 VPN 自己的 DNS 地址再次当成上游。
- 未关闭或修改用户的系统私人 DNS，未跳过 TLS 校验。

## 节点详情

- 优先读取当前配置最后生成的脚本结果，再回查脚本配置、节点集合及聚合订阅；不按相似名称猜测。
- 节点集合支持名称替换、前缀和后缀；解析与集合匹配在后台 isolate 执行。
- 生成节点、脚本改名节点和集合节点可查看；不能准确对应原订阅条目的条目只读，避免写入无效覆盖。
- 密钥字段继续遮挡，解析错误日志只记录异常类型。

## 验证与限制

- 143 项定向测试、6 项 Flutter 界面交互测试通过；`flutter analyze --no-pub` 无问题。覆盖选择器、单节点测速、配置生成、WARP、订阅持久化、配置切换、手动选择同步/回滚和 Windows 运行时校验。
- 已实际查看深浅色、长节点名、320px/1.6 倍字号、桌面及 WARP 入口/出口卡片；交互测试包含选择、长按测速和失败保留原选择。
- 真实 Windows 内核回环转发：4 组场景各 20 次，80/80 成功，验证中转组、节点集合、include-all 筛选和 include-all 入口；连接释放通过。
- 回环验证使用本地 Core X 基线二进制；本轮没有重新编译运行 dev 的原始内核二进制，dev 的构建回归由独立 CI 执行。
- 真实内核 DNS 查询：覆写模式、覆写真实地址解析、system 模式均得到成功应答。本机单次启动 70–76ms；这些是路径验证，不能据此宣称用户设备的启动或公网连接提速。
- Android 真机、系统私人 DNS、用户实际机场和浏览器组合：NOT VERIFIED，需要新 APK 复测；本机解析成功不能代替该验收。
- 带静态节点排除表达式的中转副本明确拒绝生成，仍可作为第一跳；避免改名后改变排除语义。复杂 `override-expr` 节点详情不猜测结果。
- 后置策略组要求入口和落地成员独立，展开超过 10,000 个节点时拒绝生成，防止过量配置造成卡顿；单节点和 WARP 后置不受该展开限制。
- 订阅前置策略组覆盖全部入口、或后置依赖无法估算大小的动态集合时明确报错，不静默忽略；这类入口可使用链式代理模块，后置可选择具体节点。
- Windows/Android 发布包交由 GitHub Actions 构建；触发后不持续监控 CI，不将排队或构建中记为成功。
