## چرا Fluxora

بیشتر کلاینت‌های پروکسی «اتصال برقرار شد» را پایان کار می‌دانند و قوانین، گزارش‌ها و وضعیت اتصال‌ها را در زیرمنوهای تودرتو پنهان می‌کنند. Fluxora برعکس عمل می‌کند: **نخست وضعیت را دیدنی کن، سپس کنش را در دسترس بگذار.**

این برنامه بر پایهٔ هستهٔ Mihomo (Clash Meta) و با Flutter ساخته شده و همان معماری اطلاعاتی را روی دسکتاپ و موبایل ارائه می‌دهد — داشبورد، پروکسی، پروفایل، ابزارها، گزارش‌ها، درخواست‌ها، منابع، اسکریپت‌ها و اتصال‌ها؛ نُه صفحه که هر کدام کار خود را دارند، نه انباشته و نه پنهان.

سه اصل طراحی: **خویشتن‌داری** (بدون پویانمایی تزئینی و درخشش نئونی)، **روشنی** (وضعیت همیشه از کنش چشمگیرتر است)، **قابلیت بازبینی** (متن‌باز، بدون سامانهٔ حساب کاربری، بدون وابستگی بستهٔ اعلام‌نشده).

## مزیت‌های کلیدی

- **رابط کاربری امروزی** — Material 3 با یک مجموعهٔ یکپارچهٔ توکن طراحی (رنگ، تایپوگرافی، فاصله، شعاع، پویانمایی)، نه بازنویسی سادهٔ رابط بالادستی.
- **یکدستی میان پلتفرم‌ها** — ویندوز، مک‌اواس، لینوکس و اندروید یک کدبیس Flutter و یک معماری اطلاعاتی مشترک دارند.
- **کنترل کامل پروکسی** — حالت‌های خروجی rule / global / direct، انتخاب گروه، سنجش تأخیر، زنجیرهٔ پروکسی و خروج اقامتی.
- **تصاحب شبکه** — آداپتور مجازی TUN و پروکسی سیستم، و در دسکتاپ سینی مقیم و میان‌برهای سراسری.
- **تم و جنس سطح** — روشن / تیره / پیروی از سیستم، مشکی مطلق، چهار جنس سطح (کلاسیک / شیشهٔ مات / شیشهٔ مایع / سبک) و تم «اُبسیدیَن». استخراج رنگ سیستم و رنگ تأکیدی دلخواه پشتیبانی می‌شود.
- **متن‌باز و قابل بازبینی** — GPL-3.0؛ هسته، موتور اسکریپت و وابستگی‌ها همه قابل بررسی‌اند و سامانهٔ حساب ابری وجود ندارد.

## امکانات

### اتصال

- پروکسی سیستم (دسکتاپ)
- آداپتور مجازی TUN، همراه با نوع پشته و حالت مسیریابی
- حالت‌های خروجی: rule / global / direct
- فهرست اتصال‌ها با ترافیک زنده، و بستن اتصال
- توقف خودکار هوشمند: پس از اتصال به شبکهٔ مشخص، سرویس پروکسی متوقف شود

### گره‌ها

- گروه‌های پروکسی: select / url-test / fallback / load-balance
- سنجش تأخیر و تعویض گره
- تعویض دستی فقط یک‌بار اثر می‌گذارد و به‌عنوان قفل دائمی ذخیره نمی‌شود؛ گروه‌های url-test به گرهٔ با کمترین تأخیر اندازه‌گیری‌شده بازمی‌گردند

### زنجیرهٔ پروکسی

- رلهٔ دو پرشی با یک پرش ورودی به‌همراه IP اقامتی ثابت، با ارسال به ترتیب ورود → خروج
- برای زنجیرهٔ پروکسی کارت گروه مستقل (🔗 زنجیرهٔ پروکسی) ساخته می‌شود و در کنار گروه‌های معمولی مدیریت می‌شود
- انتخاب گره و وضعیت هر پرش (ورودی / خروجی)، با سنجش تأخیر و تشخیص در سطح هر پرش
- پیش‌نمایش توپولوژی مسیر: دسترس‌پذیری و تأخیر هر پرش در یک نگاه
- برای هر پروفایل جداگانه فعال می‌شود و زنجیره‌های چندورودی صریح را نیز پشتیبانی می‌کند

### Cloudflare WARP

- خروجی WARP داخلی با گروه مستقل «🛡️ خروجی WARP» که با هر گروه پروکسی ترکیب می‌شود
- ثبت حساب Cloudflare با یک کلیک، با امکان اتصال کلید مجوز WARP+
- تنظیم endpoint / پورت، IPهای تمیز، MTU، کلید UDP و حل DNS از راه دور
- انتخاب حالت مسیریابی و تعیین شماره‌گیر بالادستی (default dialer proxy)

> برقراری اتصال به گره، محیط شبکه و وضعیت سرویس Cloudflare بستگی دارد.

### پروفایل‌ها

- مدیریت چند پروفایل (فایل محلی / پیوند اشتراک)
- درون‌ریزی و به‌روزرسانی پروفایل، ارائه‌دهندگان قوانین
- تجمیع چند اشتراک
- JavaScript برای پردازش قوانین و پیکربندی

### ابزارها

- بررسی شبکه، IP داخلی، تشخیص رفع محدودیت رسانه
- بازنویسی DNS، Sniffer و NTP
- کلید IPv6، مصرف حافظه، آمار ترافیک
- گزارش‌ها، ثبت درخواست‌ها، تشخیص اتصال
- اطلاعات اختیاری ریسک IP (به‌طور پیش‌فرض خاموش)

### رابط کاربری و شخصی‌سازی

- اجزای صفحهٔ اصلی قابل افزودن، مرتب‌سازی و حذف هستند؛ کنش اصلی اتصال همیشه می‌ماند
- نوار کناری دسکتاپ میان چیدمان ۲۰۸ پیکسلی با برچسب و ۶۸ پیکسلی آیکونی جابه‌جا می‌شود؛ موبایل از ناوبری شناور استفاده می‌کند
- روشن / تیره / پیروی از سیستم، مشکی مطلق (OLED)
- چهار جنس سطح و تم «اُبسیدیَن»؛ شدت عدسی و شفافیت جداگانه تنظیم می‌شوند
- سه منبع رنگ: پالت برند، رنگ سیستم (Android Material You)، رنگ تأکیدی دلخواه
- پویانمایی به وضعیت واقعی گره خورده و تنظیم «کاهش حرکت» سیستم را رعایت می‌کند
- سینی دسکتاپ، میان‌برهای سراسری، اجرا در هنگام ورود

### آیکون‌های برند

هشت سبک، هر یک با نسخهٔ تیره و روشن مستقل: رسمی، کلاسیک، آبی دریایی، ویژه، سرعت، آسمان، غروب، شب آبی.
از مسیر **تنظیمات → تم → آیکون برنامه** انتخاب کنید؛ رنگ آیکون و تم صفحه جداگانه تنظیم می‌شوند.

## دانلود

بسته‌ها در **[GitHub Releases](https://github.com/Tiam9173/fluxora/releases)** با نام `Fluxora-<version>-<platform>` منتشر می‌شوند.

نسخهٔ پایدار کنونی **[v1.1.1](https://github.com/Tiam9173/fluxora/releases/tag/v1.1.1)** است. **پیش‌نمایش 1.1.2-rc.2 در شاخهٔ `dev` متوقف شده**؛ شمارهٔ نسخه در کد به معنای انتشار بسته نیست — وضعیت واقعی و دانلودها را در Releases ببینید.

| پلتفرم | قالب‌ها | معماری‌ها |
|---|---|---|
| Windows 10 / 11 | نصب‌کنندهٔ `setup.exe` · `portable.zip` | amd64 · amd64-compatible · arm64 |
| macOS 12+ | `.dmg` | arm64 · amd64 · amd64-compatible |
| Linux | `.AppImage` · `.deb` · `.rpm` | amd64 · amd64-compatible (هر سه قالب) · arm64 (deb) |
| Android 8.0+ | `.apk` | arm64-v8a · armeabi-v7a · x86_64 · universal |
| iOS | کلاینت رسمی ندارد | — |

> گونه‌های `-compatible` برای پردازنده‌ها و سیستم‌های قدیمی‌تر (دستگاه‌های بدون مجموعه‌دستورهای جدید) هستند؛ روی دستگاه‌های معمولی نسخهٔ استاندارد را انتخاب کنید. این جدول قالب‌های پشتیبانی‌شده را نشان می‌دهد، نه اینکه هر بیلد آزمایشی همهٔ آن‌ها را تولید کرده باشد.

## نصب

### Windows

نصب‌کنندهٔ `setup.exe` را دانلود کنید، یا `*-windows-amd64-portable.zip` را باز کنید و `Fluxora.exe` را مستقیم اجرا کنید.

### Android

APK مناسب معماری دستگاه را از Releases دانلود و به‌صورت sideload نصب کنید.

### Linux

بسته به توزیع، `.AppImage` یا `.deb` یا `.rpm` را انتخاب کنید.

### macOS

DMG مناسب معماری خود را دانلود و باز کنید.

## استفاده و حریم خصوصی

1. اشتراک یا پروفایل محلی خود را در «پروفایل‌ها» درون‌ریزی کنید و مورد نظر را انتخاب کنید.
2. در «پروکسی» یک گره انتخاب کنید و اتصال را آغاز کنید. Fluxora اشتراک یا سرور پروکسی ارائه نمی‌دهد.
3. TUN و پروکسی سیستم بر پایهٔ پلتفرم و مجوزها کار می‌کنند؛ پروکسی سیستم تنها بر برنامه‌هایی اثر می‌گذارد که آن را رعایت می‌کنند.

به‌روزرسانی اشتراک، سنجش تأخیر، بررسی IP خروجی / رفع محدودیت و ثبت WARP با سرویس‌های مربوط تماس می‌گیرند. اطلاعات ریسک IP به‌طور پیش‌فرض خاموش است؛ با فعال‌سازی و جست‌وجو، IP بررسی‌شده به ارائه‌دهندهٔ اطلاعات فرستاده می‌شود. **«نبودِ حساب ابری Fluxora» را به «نبودِ درخواست شبکه‌ای ثالث» تفسیر نکنید.** پیش از به اشتراک گذاشتن پروفایل، گزارش یا تشخیص، نشانی اشتراک، کلیدها و اطلاعات شخصی را حذف کنید.

## پرسش‌های متداول

### Fluxora چیست؟

کلاینت مسیریابی متن‌باز و چندسکویی بر پایهٔ هستهٔ Mihomo (Clash Meta) که با Flutter ساخته شده است.

### کدام پلتفرم‌ها پشتیبانی می‌شوند؟

ویندوز، مک‌اواس، لینوکس و اندروید. کلاینت رسمی iOS وجود ندارد و در برنامهٔ کنونی هم نیست.

### متن‌باز است؟ با چه مجوزی؟

بله — **GPL-3.0**. متن کامل در [LICENSE](../LICENSE).

### چگونه پروفایل درون‌ریزی کنم؟

در صفحهٔ «پروفایل‌ها» پیوند اشتراک را بیفزایید یا فایل محلی را درون‌ریزی کنید، سپس انتخاب و متصل شوید. پیوندهای `fluxora://install-config` مستقیم درون‌ریزی می‌شوند.

### تفاوت TUN و پروکسی سیستم چیست؟

پروکسی سیستم تنها بر برنامه‌هایی اثر می‌گذارد که تنظیم پروکسی سیستم را رعایت می‌کنند. TUN از لایهٔ پایین‌تر با آداپتور مجازی ترافیک را تصاحب می‌کند، بنابراین پوشش بیشتری دارد و معمولاً به دسترسی مدیر نیاز دارد. در دسکتاپ هر دو مستقل خاموش و روشن می‌شوند.

### چرا نسخهٔ iOS وجود ندارد؟

iOS به پیاده‌سازی مستقل Network Extension و انتشار با امضای توسعه‌دهنده نیاز دارد. در برنامهٔ کنونی نیست.

### آیا داده‌های من جمع‌آوری می‌شود؟

نه. Fluxora سرویس حساب ابری و ارسال آمار داخلی ندارد. اما به‌روزرسانی اشتراک، سنجش تأخیر، بررسی IP و رفع محدودیت بر اساس پیکربندی شما با سرویس‌های ثالث تماس می‌گیرند.

## توسعه

**پیش‌نیازها**: Flutter (همراه Dart)، Android SDK/NDK و JDK، و زنجیره‌ابزار هر پلتفرم (ویندوز: Visual Studio Build Tools، مک‌اواس: Xcode، لینوکس: کتابخانه‌های توسعهٔ GTK). هسته و Helper اجزایی به Go / Rust هستند و زنجیره‌ابزار خود را می‌خواهند.

```bash
git clone https://github.com/Tiam9173/fluxora.git
cd fluxora
flutter pub get
dart run build_runner build -d
flutter analyze
flutter test
flutter run            # یا flutter build windows --release
```
